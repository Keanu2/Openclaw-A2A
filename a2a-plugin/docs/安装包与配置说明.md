# 安装包与配置说明

**即装即用（鸿蒙主路径）**

- 发布目录：[`installer/`](../../installer/)
- 安装包：`openclaw-2026.3.13.tgz`（定制 OpenClaw；内置 a2a-gateway 基线仍可能是 **1.4.3**）
- 说明：见该目录 `README.md` / `README-安装与使用.md`，以及仓库根 [`INSTALL.md`](../INSTALL.md)

**文件传输 1.6.x**：请用本仓库 `a2a-plugin` 打出的 `openclaw-a2a-1.6.2.tgz`（或同步后的 `extensions/a2a-gateway`）覆盖设备上的插件目录，再重启 gateway。不要只装嵌套归档 [`openclaw-a2a-1.4.3.tgz`](../openclaw-a2a-1.4.3/)（历史小包）。
