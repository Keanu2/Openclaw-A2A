# 安装包与配置说明

**即装即用（鸿蒙主路径）**

- 发布目录：[`installer/`](../../installer/)
- 安装包：`openclaw-2026.3.13.tgz`（定制 OpenClaw；**源树** `openclaw-source/extensions/a2a-gateway` 已同步 **1.6.2**；旧 tgz 未重打包时仍可能是旧副本）
- 说明：见该目录 `README.md` / `README-安装与使用.md`，以及仓库根 [`INSTALL.md`](../INSTALL.md)

**文件传输 1.6.x**：优先用已同步的 `extensions/a2a-gateway`，或本仓库 `a2a-plugin` 打出的 `openclaw-a2a-1.6.2.tgz` 覆盖设备插件目录后重启 gateway。不要只装嵌套归档 [`openclaw-a2a-1.4.3.tgz`](../openclaw-a2a-1.4.3/)（历史小包）。
