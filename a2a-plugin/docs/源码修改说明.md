# 源码修改说明

相对上游 A2A Gateway，本仓库（`openclaw-a2a` / 插件 ID `a2a-gateway`，当前 **`1.6.2`**）的主要源码增量如下。  
安装与配置见 [操作手册.md](./操作手册.md)；协议兼容见 [COMPATIBILITY.md](./COMPATIBILITY.md)；文件数据面见 [FILE-TRANSFER-UNIFIED-PLAN.md](./FILE-TRANSFER-UNIFIED-PLAN.md) 与 [CHANGELOG.md](../CHANGELOG.md)。

> 能力演进以**本插件仓**为准。OpenClaw 发行树若内置旧副本，部署时需用本仓库覆盖。

---

## 1. 改动边界（摘要）

| 问题 | 结论 |
|------|------|
| 业务能力主要改在哪？ | **本插件**（隧道、本地发文件、注册中心、落盘/文件名） |
| OpenClaw 核心改动大吗？ | **不大**（定制发行时默启 bundled、`plugin-sdk` 导出与依赖接线） |
| 设备上覆盖 `extensions/a2a-gateway` | 部署动作，真相源仍是本仓库 |

---

## 2. 本地文件发送（`a2a_send_local_file` / `a2a_send_file`）

| 项 | 说明 |
|----|------|
| 工具 / RPC | Agent：`a2a_send_local_file`、`a2a_send_file`；网关：`a2a.send_local_file`、`a2a.send_file` |
| 目的 | 按本机路径发文件，避免公网 URI 与命令行塞大段 base64 |
| 选路（1.6.0+） | `fileTransfer.mode`（`auto`/`quic`/`tcp`/`base64`）∩ 对端 Agent Card → `quic-v7` / `tcp-v1` / `inline-base64` |
| 默认内联上限 | `security.maxInlineFileSizeBytes` / `maxFileSizeBytes` = **50MB**（仅 inline 路径） |
| 主要文件 | `index.ts`（工具与统一发送）、`src/file-transfer*.ts`、`openclaw.plugin.json` |

发送侧传输名始终为本地 `path` 的 **basename**（忽略参数 `name`，避免模型编造 `file.jpg`）。  
未配置 `fileTransfer` 时仍按 Legacy：小文件 base64；旧工具名与隧道兼容。

---

## 3. 接收落盘与文件名

| 项 | 说明 |
|----|------|
| 内联落盘 | `fileStorage.tempDir`（未配置则用系统临时目录） |
| 流式落盘 | `fileTransfer.receiveDir`（建议与用户可见目录对齐，如 Phone：`…/Docs/OPENCLAW`） |
| 文件名 | 按 FilePart / offer 的 `name` 落盘；重名追加 ` (n)`（no-clobber） |
| 提交（1.6.2） | 优先同目录 `link(2)`；鸿蒙共享媒体 FS 上 `EPERM` 等则 `rename` / `copyFile`（`file-transfer-store.ts`） |
| 通知（1.6.1） | 收端 `DATA_COMMITTED` 后再发 `a2a-transfer://`；status 可返回 `RECEIVING` |
| 线上 FilePart | 内联：`{ name, mimeType, bytes }`；流式成功后：小型 `uri: a2a-transfer://<transferId>` |
| 接收兼容 | 除 `file.name` 外，兼容 `fileName` / `filename` / `file_name` |
| 主要文件 | `index.ts`、`src/executor.ts`、`src/file-transfer-store.ts` |

聊天侧应原样回报保存绝对路径，勿改写成历史路径或工作区里写死的旧图路径（属提示词/TOOLS 约束，非网关强制）。

## 4. 嵌入隧道与重连

| 项 | 说明 |
|----|------|
| 目的 | 跨 NAT 经中继互通；缓解半死连接与「重连耗尽后永不再连」 |
| 行为 | 心跳超时强制断开、指数退避、默认无限重连、协议层 ping |
| 主要文件 | `src/tunnel/session.ts` 等 |

配置入口见操作手册「隧道 / NAT」章节。

---

## 5. 注册中心（远场发现）

| 项 | 说明 |
|----|------|
| 目的 | HTTP 注册/发现，减少手写 `peers` |
| 主要文件 | `src/registry-client.ts`，以及 `index.ts` / schema 中的 `registry` 配置 |
| 聊天入口 | Agent 工具 `a2a_registry_register` / `a2a_registry_list`；Gateway `a2a.registry.register` / `a2a.registry.list`（dataset 用配置，返回 `serviceId` + `tunnelDeviceId` + AgentCard） |

配置与排障见操作手册「注册中心」章节。
