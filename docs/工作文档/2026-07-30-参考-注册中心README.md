# Agent 注册中心接入流程

## 1. 服务入口

| 入口 | 地址 |
|---|---|
| 注册中心 | `http://121.37.53.35:8000` |
| 健康检查 | `GET /api/warmup-status` |
| API 文档 | `GET /docs` |

核心 API：

| 操作 | API |
|---|---|
| 列出命名空间 | `GET /api/datasets` |
| 创建命名空间 | `POST /api/datasets` |
| 注册 A2A Agent | `POST /api/datasets/{dataset}/services/a2a` |
| 发现 Agent | `GET /api/datasets/{dataset}/services` |
| 获取指定 Agent | `GET /api/datasets/{dataset}/services/{service_id}` |
| 获取可调用 Agent Card | `GET /api/datasets/{dataset}/services/{service_id}/agent-card?route=direct\|relay` |
| 通过注册中心调用 Agent | `POST /a2a/{dataset}/{service_id}` |
| WebSocket 隧道状态 | `GET /api/tunnel/status` |
| 更新 Agent Card | `PUT /api/datasets/{dataset}/services/{service_id}` |
| 注销 Agent | `DELETE /api/datasets/{dataset}/services/{service_id}` |

注册中心负责保存、发现 Agent Card；启用 Relay 后可将 A2A 请求转发给目标 Agent。

Relay 的集成代码和运行机制见 [A2A Relay 集成说明](README_RELAY_INTEGRATION.md)。

HarmonyOS 端侧设备发现与跨设备调用见
[软总线接入说明](README_SOFTBUS.md)。

手机端 OpenClaw 已安装只读 `agent_registry` Tool；参数、安装路径和调用方式见
[OpenClaw Agent Registry Tool](openclaw-tools/agent-registry/README.md)。

## 2. Agent 提供入口

Agent 至少提供：

```text
GET  /health
GET  /.well-known/agent.json
GET  /.well-known/agent-card.json
POST /a2a
```

Agent Card 中的 A2A 地址必须能被注册中心服务器访问。使用 Relay 时：

- 目标主机必须填写 IP 地址，不能填写域名。
- 协议绑定必须是 `JSONRPC` 或 `HTTP+JSON`。
- 当前开发环境允许转发到任意合法 IP 和端口。

Agent Card 最小结构：

```json
{
  "name": "My Agent",
  "description": "Agent 功能说明",
  "version": "1.0.0",
  "protocolVersion": "1.0",
  "url": "http://10.0.0.21:9000/a2a",
  "preferredTransport": "JSONRPC",
  "capabilities": {},
  "skills": [
    {
      "id": "skill-id",
      "name": "skill-name",
      "description": "技能说明",
      "tags": ["tag"]
    }
  ],
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["application/json"]
}
```

## 3. 创建命名空间

```bash
curl -X POST http://121.37.53.35:8000/api/datasets \
  -H "Content-Type: application/json" \
  -d '{"name":"cli_agents"}'
```

命名空间已存在时跳过。

## 4. 注册 Agent

请求：

```bash
curl -X POST \
  http://121.37.53.35:8000/api/datasets/cli_agents/services/a2a \
  -H "Content-Type: application/json" \
  -d '{
    "service_id": "my-agent",
    "agent_card": {
      "name": "My Agent",
      "description": "Agent 功能说明",
      "version": "1.0.0",
      "protocolVersion": "1.0",
      "url": "http://10.0.0.21:9000/a2a",
      "preferredTransport": "JSONRPC",
      "capabilities": {},
      "skills": [{
        "id": "skill-id",
        "name": "skill-name",
        "description": "技能说明",
        "tags": ["tag"]
      }],
      "defaultInputModes": ["text/plain"],
      "defaultOutputModes": ["application/json"]
    },
    "persistent": true
  }'
```

成功响应：

```json
{
  "service_id": "my-agent",
  "dataset": "cli_agents",
  "status": "registered"
}
```

同一 `service_id` 再次注册会覆盖 Agent Card。

## 5. 发现 Agent

列出全部 Agent：

```bash
curl "http://121.37.53.35:8000/api/datasets/cli_agents/services?fields=detail"
```

按字段精确筛选：

```bash
curl "http://121.37.53.35:8000/api/datasets/cli_agents/services?fields=detail&name=My%20Agent"
```

按服务 ID 获取：

```bash
curl \
  http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent
```

获取直连 Agent Card：

```bash
curl \
  "http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent/agent-card?route=direct"
```

获取注册中心转发 Agent Card：

```bash
curl \
  "http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent/agent-card?route=relay"
```

## 6. 接入转发服务

### 6.1 注册中心配置

```bash
export A2X_RELAY_ENABLED=true
export A2X_RELAY_PUBLIC_BASE_URL=http://121.37.53.35:8000
export A2X_RELAY_ALLOW_ALL_TARGETS=true
export A2X_RELAY_FORWARD_AUTHORIZATION=true
```

全开放模式仍拒绝域名、云元数据、链路本地、组播、保留地址和非法 URL。

重启注册中心后，调用方按以下流程使用 Relay：

1. 发现目标 `service_id`。
2. 获取 `route=relay` 的 Agent Card。
3. 从 Card 的 `supportedInterfaces` 或 `url` 读取转发地址。
4. 向该地址发送目标 Agent 支持的 A2A 请求。

获取并调用 Relay 地址：

```bash
RELAY_URL=$(curl -fsS \
  "http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent/agent-card?route=relay" \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["url"])')

curl -X POST "$RELAY_URL" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc":"2.0",
    "id":"req-1",
    "method":"SendMessage",
    "params":{
      "message":{
        "role":"ROLE_USER",
        "messageId":"msg-1",
        "parts":[{"text":"hello"}]
      }
    }
  }'
```

Relay 只转发已注册且健康的 Agent。请求体保持不变；普通 JSON 和 SSE 响应都会透传。

直连时，把 `route=relay` 改为 `route=direct`，再调用返回 Card 中的原始地址。

| 模式 | 使用条件 |
|---|---|
| `direct` | 调用方可以直接访问目标 Agent |
| `relay` | 调用方只能访问注册中心，且注册中心可以访问目标 Agent |

### 6.2 端侧 WebSocket 隧道

云端无法直接访问目标 Agent 时，设备运行现有 `tunnel-client/client.js` 并连接：

```text
ws://121.37.53.35:8001
```

只发现 Agent 时，设备首帧用 `device_id` 注册。发布本机 Agent 时，
同一帧增加 `dataset`、`service_id` 和 `agent_card`。注册中心保存
`dataset/service_id → device_id` 映射：映射在线时 Relay 走 WebSocket，
离线时继续按 Agent Card URL 走 HTTP。发现使用
`discover_request → discover_response`。此隧道与 HTTP Relay 由同一个
`agentregistry.service` 托管。

旧版客户端只发送 `device_id` 时，可启用
`A2X_TUNNEL_AUTO_BIND_REGISTERED_SERVICES=true`，并提前在 Agent Card
的 `metadata.tunnelDeviceId` 中写入相同设备 ID。设备上线后注册中心会
自动建立服务绑定。目标 Agent 需要 Bearer 鉴权时，调用 Relay URL 的
请求必须携带 `Authorization`。

## 7. Python 最小接入代码

```python
import uuid
import requests

REGISTRY = "http://121.37.53.35:8000"
DATASET = "cli_agents"


def register_agent(service_id: str, agent_card: dict) -> dict:
    response = requests.post(
        f"{REGISTRY}/api/datasets/{DATASET}/services/a2a",
        json={
            "service_id": service_id,
            "agent_card": agent_card,
            "persistent": True,
        },
        timeout=10,
    )
    response.raise_for_status()
    return response.json()


def relay_agent_card(service_id: str) -> dict:
    response = requests.get(
        f"{REGISTRY}/api/datasets/{DATASET}/services/"
        f"{service_id}/agent-card",
        params={"route": "relay"},
        timeout=10,
    )
    response.raise_for_status()
    return response.json()


def send_message(service_id: str, text: str) -> dict:
    card = relay_agent_card(service_id)
    payload = {
        "jsonrpc": "2.0",
        "id": str(uuid.uuid4()),
        "method": "SendMessage",
        "params": {
            "message": {
                "role": "ROLE_USER",
                "messageId": str(uuid.uuid4()),
                "parts": [{"text": text}],
            }
        },
    }
    response = requests.post(card["url"], json=payload, timeout=30)
    response.raise_for_status()
    return response.json()
```

`payload` 需符合目标 Agent Card 声明的 A2A 版本。注册中心只负责发现、地址改写和请求转发。

## 8. 更新与注销

更新字段：

```bash
curl -X PUT \
  http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent \
  -H "Content-Type: application/json" \
  -d '{"description":"新的功能说明"}'
```

注销：

```bash
curl -X DELETE \
  http://121.37.53.35:8000/api/datasets/cli_agents/services/my-agent
```

当前注册中心为匿名模式；生产环境需启用鉴权或限制安全组来源。
