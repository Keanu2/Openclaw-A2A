## 1. 背景：要解决什么

### 1.1 落盘目录

此前接收 inline 文件时，默认落到：

```text
os.tmpdir() + "/a2a-files"
```

在 HarmonyOS 上通常偏系统临时目录，用户在「文件管理 / 下载」里不好找。

目标：

| 设备 | 希望用户能在文件管理看到的位置 |
|------|--------------------------------|
| PC（MateBook / HW-PC1） | 下载目录下的 `OPENCLAW` |
| Phone（Mate 60 / HW-Phone1） | 文档目录下的 `OPENCLAW` |

### 1.2 文件名

旧实现 `saveBase64File` 落盘名为：

```text
{UUID}{扩展名}
例如：e99e07ce-4204-47b5-b2cb-34abfe62c955.txt
```

用户只能靠 Agent 话术里的「原文件名」对照，磁盘上文件名丢失。

目标：磁盘上**尽量保留发送方给出的原文件名**；重名时追加 ` (1)`、` (2)`。

---

## 2. UI 路径 vs 真实文件系统路径（重要）

用户在电脑文件管理器里看到的路径，与 shell/`hdc` 下的路径**不一定相同**。

| 设备 | 用户描述 / UI 观感 | hdc 实测存在且可写的路径 | 是否采用 |
|------|-------------------|-------------------------------|----------|
| PC | `/storage/Users/currentUser/Download/OPENCLAW` | **不存在**（`/storage/Users` 无此节点） | 否 |
| PC | （同 UI「下载/OPENCLAW」） | **`/storage/cloud/100/files/Docs/Download/OPENCLAW`** | **是（配置值）** |
| PC | （另有 Docs/OPENCLAW） | `/storage/cloud/100/files/Docs/OPENCLAW` | 未采用（按用户要求放 Download 下） |
| Phone | `/storage/media/100/local/files/Docs/OPENCLAW` | **存在且可写** | **是** |

结论：

- **PC 配置必须写 cloud 真实路径**，不能写 UI 上的 `/storage/Users/currentUser/...`。  
- Phone 用户给的路径与实测一致，可直接用。  
- 配置写入：`plugins.entries.a2a-gateway.config.fileStorage.tempDir`。

## 4. 每个文件具体怎么改

### 4.1 `src/executor.ts` — 保留原文件名

#### 旧逻辑（问题）

```ts
const id = crypto.randomUUID();
const filename = `${id}${ext}`;
```

#### 新逻辑

1. **`sanitizeFileName`**：只保留 basename；去掉控制字符与 `<>:"|?*`；最长 180；空则 `file`。  
2. **`uniquePathForName`**：  
   - 无扩展名时，用 `extensionForMime(mime, name, buffer)` 补后缀；  
   - 若目标已存在：`name.ext` → `name (1).ext` → `name (2).ext` …；  
   - 极端冲突（>10000）再退回短 UUID 后缀。  
3. **`saveBase64File`**：`mkdirSync` → 算唯一路径 → `writeFileSync(..., { mode: 0o664 })` → 尽量 `chown` 为目录的 uid/gid（方便非 root 的文件管理器打开）。  
4. 模块级 `fileTempDir` 仍在 `OpenClawAgentExecutor` 构造时赋值：

```ts
fileTempDir = config.fileStorage?.tempDir || path.join(os.tmpdir(), "a2a-files");
fs.mkdirSync(fileTempDir, { recursive: true });
```

**效果对照**

| | 改前 | 改后 |
|--|------|------|
| 磁盘文件名 | UUID | 原名（如 `hello-filename-test.txt`） |
| 同名再收 | 不会撞名（UUID） | `hello-filename-test (1).txt` |
| 无扩展名 | 靠 MIME 拼 UUID+ext | 原名 + MIME/嗅探扩展名 |

### 4.2 `index.ts` — 接通 `fileStorage` 配置

在 `parseConfig` 返回值中增加：

```ts
fileStorage: (() => {
  const fsCfg = asObject(config.fileStorage);
  const tempDir = asString(fsCfg.tempDir, "").trim();
  if (!tempDir) return undefined;
  return {
    tempDir: resolveConfiguredPath(tempDir, tempDir, resolvePath),
  };
})(),
```

**效果：** `openclaw.json` 里写的 `fileStorage.tempDir` 会进入运行时；未配置则仍用 `tmpdir()/a2a-files`。

### 4.3 `index.ts` — 发送路径白名单

`isAllowedLocalPath` 的 `allowedPrefixes` 现为：

```ts
const allowedPrefixes = [
  "/data/local/",
  "/storage/media/",
  "/storage/cloud/",   // PC Download/OPENCLAW 真实前缀
  "/storage/Users/",   // 预留 UI 风格路径（若系统将来映射）
  "/mnt/user/",
  "/mnt/hmdfs/",
  "/home/",
];
```

**为什么加 `/storage/cloud/`：** 接收目录落在 cloud Download 下后，用户可能再从该目录 `a2a_send_local_file` 发出去；旧白名单不含 cloud 会被 `Path rejected`。

### 4.4 `openclaw.plugin.json` — schema

```json
"fileStorage": {
  "type": "object",
  "additionalProperties": false,
  "description": "Where inbound A2A inline files are saved on this device.",
  "properties": {
    "tempDir": {
      "type": "string",
      "description": "Directory for received files. Original filenames are preserved; conflicts become name (1).ext"
    }
  }
}
```

**效果：** Phone 上若仍用旧 schema（无此字段），开 `fileStorage` 会 `Config invalid: must NOT have additional properties`。部署时须同步 schema 到实际校验路径（含 npm 自带扩展目录）。

### 4.5 设备 `openclaw.json` 片段

**PC（HW-PC1）：**

```json

  "tempDir": "/storage/cloud/100/files/Docs/Download/OPENCLAW"
}
```

**Phone（HW-Phone1）：**


## 5. 运行时数据流（接收）

```text
对端 a2a.send / a2a.send_local_file
  → 隧道/直连 → 本机 :18800 A2A
  → OpenClawAgentExecutor 解析 FilePart
  → formatFilePartAsText
       → saveBase64File(bytes, name, mimeType)
            → 目录 = fileStorage.tempDir（已配置）
            → 文件名 = 净化后的原名（冲突加 (n)）
  → Agent 话术：「接收成功 + 完整保存路径」
```

发送侧文件名来源：

- `a2a.send_local_file` / Tool：**强制** `path.basename(本地路径)`，**忽略** 调用方传入的 `name`（Agent 常编造 `file.jpg`）  
- 该 basename 进入 A2A FilePart，接收侧据此落盘  
- 详见 [`2026-08-03-改动说明-传输文件名与路径回报.md`](./2026-08-03-改动说明-传输文件名与路径回报.md)

## 7. 以后如何改落盘目录

只需改**该设备** `openclaw.json` 的 `fileStorage.tempDir`，重启 gateway。  
注意：

1. 路径必须是 **shell 下真实存在、进程可写** 的绝对路径（先用 `hdc shell ls` / `touch` 验证）。  
2. UI 显示路径若与 shell 不一致，以 shell 为准写入配置。  
3. 若新目录不在发送白名单前缀下，又要从该目录发出，还需改 `index.ts` 的 `allowedPrefixes` 并同步插件。  
4. Phone 改配置后若报 `additional properties`，检查 npm 扩展目录里的 `openclaw.plugin.json` 是否含 `fileStorage`。
