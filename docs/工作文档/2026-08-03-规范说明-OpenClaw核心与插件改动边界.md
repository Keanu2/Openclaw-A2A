# 2026-08-03-规范说明-OpenClaw核心与插件改动边界

> **目的**：回答「原版 OpenClaw 改动大不大？主要改插件还是核心？」并分别罗列文件、原因、结果。  
> **依据**：`docs/工作文档/` 各改动说明/总览、`openclaw-custom/CUSTOM-A2A.md`、设备部署笔记；2026-08-03 复核。

> **定制发行树**：`D:\openclaw\openclaw-custom`（基于官方 **v2026.3.13-1**）

## 0. 总判断（先看这里）

| 问题 | 结论 |
|------|------|
| 对原版 OpenClaw **业务内核**改动大吗？ | **不大**。主要是「把 a2a-gateway 打成 stock 内置并默启」+ SDK/依赖接线。 |
| 主要改在哪里？ | **主要在插件** `Openclaw-A2A`（隧道、本地发文件、注册中心、落盘/文件名等）。 |
| 设备上覆盖 `node_modules/openclaw/extensions/a2a-gateway` 算改核心吗？ | **不算**。那是把插件仓部署进安装树；真相源仍是插件仓。 |
| custom 树内插件副本是否最新？ | **否**。`openclaw-custom/extensions/a2a-gateway` 约 **1.3.0**（无 `send_local_file` / registry）；现网靠覆盖同步到 **1.4.3-tunnel.3**。 |

### 粗略工作量拆分

| 类别 | 约占比 |
|------|--------|
| 插件仓功能开发（tunnel / 50M / registry / 落盘等） | **75–85%** |
| 设备配置 + TOOLS/MEMORY | **8–12%** |
| Launcher / start / env（HarmonyOS） | **3–5%** |
| OpenClaw-custom 核心接线（BUNDLED 默启、plugin-sdk、pack 依赖） | **5–10%** |
| 覆盖设备 bundled 副本 | 部署动作（工作量小，运行时关键） |

**一句话：** 能力演进在插件仓；`openclaw-custom` 负责发行时内置；现网设备靠覆盖插件副本跟上 `1.4.3-tunnel.3`。
