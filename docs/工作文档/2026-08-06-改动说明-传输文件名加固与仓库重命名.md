| | 说明 |

| 文件 | 改了什么 | 为什么 |
|------|----------|--------|
| **`index.ts`** | `FilePart.file` 从 `{ bytes, name, mimeType }` 改为 `{ name, mimeType, bytes }` | JSON 序列化顺序下，超大 `bytes` 在前时，部分链路会出现 `name` 丢失 |

## 3. 代码怎么改

### 3.1 `index.ts` — FilePart 字段顺序

```ts
// Put name/mimeType BEFORE bytes so large base64 cannot push metadata
// past body/parser limits or partial-JSON cutoffs (seen as wire name="file").
parts.push({
  kind: "file",
  file: { name, mimeType, bytes },
});
```

### 3.2 `src/executor.ts` — 接收侧 name 回退

```ts
const rawName =
  asString(file.name) ||
  asString(file.fileName) ||
  asString(file.filename) ||
  asString(file.file_name) ||
  "file";
```

## 4. 验收

```bash

openclaw gateway call a2a.send_local_file --timeout 300000 --params \
  '{"peer":"HW-Phone1","path":"/storage/media/100/local/files/Docs/Desktop/华为公司发展介绍.pptx"}'
```

**成功标准：**

3. 手机会话入站文案：`传输文件名: 华为公司发展介绍.pptx`（不是 `file`）

2026-08-06 11:22 复测已通过。旧的 `file.pptx` 可手动删除，不影响新传输。
