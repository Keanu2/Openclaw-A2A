## 命名规范

```text
YYYY-MM-DD-类别-主题.md
```

| 类别 | 用途 |
|------|------|
| `参考` | 外部文档备份 |
| `改动说明` | 某次功能/修复的详细说明 |
| `测试报告` | 实测对比、时延等 |
| `变更记录` | 设备部署与排查长文 |
| `规范说明` | 流程/TOOLS 等规范 |
| `代办` | 尚未落地的计划 |
