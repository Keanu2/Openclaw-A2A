# 工作文档目录

本目录集中存放本仓库的**本地工作记录**（改动说明、测试报告、同步/变更记录、操作手册等）。

> 工程正式文档仍保留在仓库根目录：`README.md`、`CHANGELOG.md`，以及 `docs/COMPATIBILITY.md`、`docs/device/` 等。

## 命名规范

```text
YYYY-MM-DD-类别-主题.md
```

| 段 | 说明 | 示例 |
|----|------|------|
| `YYYY-MM-DD` | 文档主日期（撰写或覆盖的业务日） | `2026-07-30` |
| `类别` | 固定词表，见下表 | `改动说明` |
| `主题` | 简短中文/中英混排主题，用 `-` 连接关键词 | `隧道重连` |

### 类别词表

| 类别 | 用途 |
|------|------|
| `参考` | 外部文档备份（如注册中心 README） |
| `改动说明` | 某次功能/修复的详细改动与部署说明 |
| `测试报告` | 实测对比、时延、公平性等报告 |
| `变更记录` | 偏 changelog / 设备部署长文 |
| `同步说明` | 源码如何同步到设备的短说明 |
| `规范说明` | TOOLS/Harness 等规范与前后对比 |
| `操作手册` | 项目详解与操作类长文 |

新文档请直接按此规范命名并放入本目录。
