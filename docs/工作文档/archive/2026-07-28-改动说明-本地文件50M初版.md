## 1. 改动目标

1. 支持通过**本地绝对路径**发送文件（进程内读盘 → base64 FilePart），避免 `gateway call a2a.send --params` 塞入巨大 base64 触发 `E2BIG` / ARG_MAX。
2. 将内联文件默认上限从 **10MB 提升到 50MB**，与 URI 附件 `maxFileSizeBytes` 对齐。
3. 为 Agent / CLI 提供明确入口：`a2a_send_local_file` / `a2a.send_local_file`。
4. 文档与 skill 脚本、单测与上述行为保持一致。

## 4. 功能细节（`index.ts`）

### 4.1 新增 Gateway 方法：`a2a.send_local_file`

**参数：**

| 字段 | 必填 | 说明 |
|------|------|------|
| `peer` | 是 | 配置中的 peer `name` |
| `path` | 是 | 本机绝对路径 |
| `name` | 否 | ~~文件名覆盖~~（历史）；现网 **忽略**，传输名强制 `basename(path)`，见 08-03 改动说明 |
| `mimeType` | 否 | MIME 覆盖（默认按扩展名检测） |
| `text` | 否 | 随文件附带的文本 |
| `agentId` | 否 | 对端 OpenClaw agent 路由 |

**行为：**

1. 校验 peer 存在  
2. 校验 path 为绝对路径且落在白名单根下  
3. `stat` + `checkFileSize(..., maxInlineFileSizeBytes)`  
4. MIME 校验  
5. `readFileSync` → base64 → `kind: "file"` FilePart  
6. `client.sendMessage`（与 `a2a.send` 同一套韧性/健康检查配置）

**路径白名单：**

- `/data/local/`
- `/storage/media/`
- `/mnt/user/`
- `/mnt/hmdfs/`
- `/home/`

路径匹配时会规范化反斜杠，并去掉 Windows 盘符（如 `C:`），便于在 Windows 上跑单测，同时 HarmonyOS 设备仍按 POSIX 路径工作。

### 4.2 新增 Agent 工具：`a2a_send_local_file`

与上述 RPC 共用 `sendLocalFileCore`。说明文案明确：

- 用于本机 Desktop / Photo / 图库等本地文件  
- **不要**用 `a2a_send_file`（那是公网 URI）  
- **不依赖** SoftBus 配对  

### 4.3 注册位置

`a2a.send_local_file` 注册在 `if (api.registerTool)` **之外**，与 `a2a.send` 同级，避免仅有 gateway、无 tool API 时方法未挂上。

### 4.4 默认上限

| 配置项 | 旧默认 | 新默认 |
|--------|--------|--------|
| `security.maxFileSizeBytes` | 50MB | 50MB（不变） |
| `security.maxInlineFileSizeBytes` | **10MB** | **50MB** |

`parseConfig` 中 `asNumber(..., 52_428_800)` 与 `openclaw.plugin.json` schema default 已对齐。

## 5. 为什么要这么改

| 问题 | 原因 | 本仓库对策 |
|------|------|------------|
| CLI 传 MB 级文件失败 | argv 装不下 base64（ARG_MAX≈128KB） | 只传短 `path`，进程内读文件 |
| 两端/文档与默认不一致 | schema 与 parseConfig 默认仍是 10MB inline | 默认统一 50MB |
| Agent 误用 URI 工具或 SoftBus | 缺少「本地路径」一等公民工具 | 新增 `a2a_send_local_file` 并写进 README/手册 |
| 仅改设备上的副本难维护 | 集成版仍带旧代码 | 先落源码，打包时再合入 |

---

## 6. 带来的好处

1. **大文件可发**：常见照片/文档可走本地路径 API，上限默认 50MB。  
2. **CLI 安全**：`gateway call` 的 params 保持小体积，不再炸 shell。  
3. **聊天可用**：Agent 有明确 tool，减少「配对/权限」类误操作路径。  
4. **默认开箱更合理**：新安装未手写 security 时也是 50MB inline。  
5. **可测**：单测覆盖注册、拒绝非法路径、读盘发送。  
6. **与 skill 脚本一致**：`a2a-send.mjs --file-path` 同样 50MB。

## 7. 用法示例

```bash
# 文本仍可用 a2a.send
openclaw gateway call a2a.send --timeout 300000 \
  --params '{"peer":"HW-Phone1","message":{"text":"hello"}}'

# 本地文件（推荐）
openclaw gateway call a2a.send_local_file --timeout 300000 \
  --params '{"peer":"HW-Phone1","path":"/storage/media/100/local/files/Docs/Desktop/Sunflower.jpeg"}'
```

Skill 脚本（直连 peer URL 时）：

```bash
node skill/scripts/a2a-send.mjs --peer-url http://127.0.0.1:18800 \
  --token <token> --file-path /path/to/file.jpg --message "see file"
```

## 9. 集成 / 打包注意（当前暂不打包）

以后打包时请务必：

1. 用本目录（或等价合并结果）更新集成版中的 a2a-gateway 插件源码。  
2. **同步覆盖** OpenClaw 包内 bundled：  
   `.../node_modules/openclaw/extensions/a2a-gateway/`  
   （手机上 bundled 会优先加载；只改外部 extensions 可能仍报 `unknown method`）。  
3. 如需样机默认 50MB，检查发行配置模板是否写出 `maxInlineFileSizeBytes`。  
4. SoftBus 是否默认关闭由产品决定，不在本插件代码范围内。
